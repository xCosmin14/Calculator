## ✨ Features

- ✅ Designed with maximum efficiency in mind, this Calculator app only takes 22MB of memory (because of the JavaScript layer and compiler of QML) and is designed to retain as little information in the memory due to the efficient algorithms used: hard-coded hash-tables for easy lookup, branchless programming (where it could be applied)
- ✅ Exponential function
- ✅ Trigonometrical functions (sin, cos, tan, ctg/ctan)
- ✅ Square root
- ✅ Logarithms (Log (base 2), Ln (base e), Lg (base 10))
- ✅ Factorial calculation (using the CMath tgamma function)
